# My Idol, BooBoo ✦

A responsive, static browser rhythm game designed for GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `my-idol-booboo`).
2. Upload **all contents** of this folder to the repository root. Keep `assets/`, `index.html`, `styles.css`, and `game.js` together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to finish publishing; the site URL will appear in Settings → Pages.

No build step or package installation is required.

## Features
- Responsive home, song selection, rhythm stage, results, photocard album, room customization, quests, and settings.
- Keyboard controls: D / F / J / K. Touch controls are shown on mobile.
- Original synthesized tones generated with Web Audio; no external music files or commercial tracks included.
- High scores, cards, room theme, and preferences saved in this browser using localStorage.
- The included photocard sheet is a visual concept collage. Individual user photos can be added as separate card assets in a future pass.

## Notes
- Google Fonts are optional; the browser falls back to system fonts if unavailable.
- Progress is local to each browser/device and does not sync automatically.
